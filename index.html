Google Sheets Setup Guide

1
Open your Google Sheet. Click Extensions → Apps Script. Delete all existing code in the editor.
2
Click the button below to copy the script code, then paste it into the editor and press Ctrl+S.

      
3
Click Deploy → New deployment. Set Type = Web app, Execute as = Me, Who has access = Anyone. Click Deploy.

      
4
Google will ask for authorization — follow the prompts with your Google account. Then copy the Web App URL shown.

      
5
Paste the URL in the setup bar at the top and click Connect to Sheets. This is saved permanently on this computer — no need to do this again.

      

        One-time only: Once connected, the URL is saved in the browser. You never need to enter it again on the same computer, even after closing and reopening the file.


        Keep the URL private — anyone with it can write to your Sheet.
